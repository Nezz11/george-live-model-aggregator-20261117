A Node 22 router for the OpenAI Chat Completions and Anthropic Messages APIs. It selects eligible free OpenRouter models by capability and the trial ratings, retries recoverable failures, and preserves upstream completion text and usage.

## Run it

```sh
node main.ts # In the make.fun trial environment
```

Set MAKEFUN_PROMPT_FILE to the supplied brief before running node main.ts --list.
